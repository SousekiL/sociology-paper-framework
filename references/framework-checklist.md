# 社会学期刊问题框架检查表

## 从话题到问题

把宽泛话题改写为“在何种情境中，什么机制使 X 影响 Y；对谁、经由谁、为何会不同”。先指定对象、时空、结果变量和比较基线。研究问题必须允许被证据推翻。

## 方法与结论的匹配

| 目标 | 合适设计 | 结论边界 |
| --- | --- | --- |
| 描述分布/差异 | 概率样本、行政统计、可复现文本统计 | 描述或关联 |
| 解释机制 | 过程追踪、深描访谈、民族志、混合方法 | 条件性机制解释 |
| 估计政策/事件影响 | 面板固定效应、DiD、断点、匹配、事件研究 | 需要识别假设与诊断才可谈因果 |
| 比较制度逻辑 | 多案例比较、QCA、比较历史分析 | 有边界的类型/机制命题 |

## 常用中国数据入口

- CGSS：中国综合社会调查；阶层、态度、家庭、工作与社会参与。
- CFPS：中国家庭追踪调查；个体—家庭—社区追踪，适合生命历程与不平等。
- CLDS：中国劳动力动态调查；就业、劳动关系、流动与社会保障。
- CHARLS：中国健康与养老追踪调查；中老年健康、照护、家庭和退休。
- CHFS：中国家庭金融调查；财富、债务、金融与家庭决策。
- CHNS：中国健康与营养调查；健康、消费、社区环境的长期变化。
- 中国城市统计年鉴/省市统计年鉴、人口普查、国家统计局；地区与政策强度。
- 中国裁判文书网、政府公开数据、招聘/平台公开信息；需要记录抓取规则、缺失机制、合规与可复现性。

说明是否公开、是否需机构申请、是否含地理/个体敏感信息；不要暗示获得自己没有访问权限的微观数据。
